# Contributing to TrustGate

Thank you for considering contributing to TrustGate!

## Getting Started
- Fork the repository
- Clone: `git clone https://github.com/KarthikUdyawar/trustgate.git`
- Install dependencies: `poetry install`
- Create a feature branch: `git checkout -b feature/branch`

## Code Style
- Follow PEP8
- Use type hints
- Write tests

## Submitting Changes
- Run tests: `pytest`
- Open a pull request

Happy coding!
